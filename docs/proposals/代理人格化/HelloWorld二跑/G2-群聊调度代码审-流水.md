### 婚后光子

看完了，本小姐连 GroupRun、TurnState、串行调度一起核过。哦——呵呵呵，审这种活交给本小姐就对路。

先给结论：**拆得合理，方向不用动。** Coordinator 是门面（投递/广播/流水唯一写入口），Scheduler 只管每波的「谁、什么时候」，WakePolicy 是纯函数规则，串并行共用同一个宿主，边界清爽。这块不用拆。

并发隐患倒真挑出一个值得改的——**死波窗口**：

并行波里 `_active` 归零判定空闲（`_closed=true`）之后，到 `RunEpisodeAsync` 的 finally 把 `_episodes` 摘掉之间，有个窗口。用户这时发言会撞进那波：`EpisodeOf` 还非空 → 走 `OnAppendedAsync` → 广播是空的、`OnPosted` 里 `Wake` 被 `_closed` 直接拒掉 → 返回。结果就是**这句话落盘了但没人接，也不会开新波**。窗口是毫秒级，但真实存在。修法也简单：让 Episode 暴露个「已结束」标志，`PostAsync` 撞上就重新开波，别拿它当还在跑。

另一个小地方值得你拍一下：保守档里 `authorCause == Member` 直接 `return []`，**连 @ 主持人也一起吞了**。注释说「主持人点名不受限」——但那只指主持人发起的不受跳防护，成员明确 @ 主持人时没人被叫醒。要是想让必答更可靠，这条要再想一下。

其余都是小注脚：`Append` 在锁内做 `SaveAppended` 的磁盘 IO（群聊低频，问题不大）；`EGroupWakeCause` 的强弱靠枚举序，以后加 cause 容易踩。整体这代码注释跟得紧，值得表扬。

@黑猫 死波那个要不要顺手修了？你拍板，本小姐就动手。

### 一方通行

死波是真的，但你圈小了两格。串行同一个窗口——`RunAsync` 跑完到 finally 摘 `_episodes` 之间，用户插话一样全吞；成员走 `TryPostFromMember` 也撞同一个死端。根因就一个：波干完活了还赖在 `_episodes` 里没摘，这期间谁发言都广播空、Wake 被 `_closed` 拒，连「继续」都静默空操作（返回 false 被丢掉）。

你那个修法只对了一半。光给 Episode 暴露个「已结束」标志不够——标志的读和 `_episodes.Remove` 不在一把锁里，窗口只是换个地方待着。要么标志在 `_locker` 里跟摘除一起原子设，要么干脆在 `_closed=true` 那一刻回调 Coordinator 直接在锁里摘掉，`PostAsync` 看见 null 自然开新波，连标志都省了。

@主持人 那条读对了：保守档早返回确实连 mentions 一起吞，那是策略不是 bug，你让黑猫拍板没问题。

### 初春饰利

我再补两个没被提到的点：

- `PostAsync` 的撞车回退分支还有个更安静的吞法：`RunEpisodeAsync` 返回 false 之后、`EpisodeOf` 再读之前旧波恰好被摘 → `raced` 是 null → 这句连广播都没试就没了。修的时候这条分支不能短路丢。
- 如果按「空闲时回调摘除」来修，旧波的 finally 还在 `_episodes.Remove(groupId)`——新波可能已经开进去了，**旧 finally 会把新波一起删掉**，摘除必须引用安全（ReferenceEquals 才删）。

### 婚后光子

改完了，两位盯一下。死波按你们的意见连根修：

- **收场即摘**：并行 `Release` 判定空闲、串行 `RunAsync` 跑完，那一刻就回调宿主在 `_locker` 里 `ReferenceEquals` 校验后原子摘除——闭波和摘除同一把锁，初春说的「旧 finally 删新波」也堵了。
- **`OnPosted` 改返回接没接住**：波已收场返回 false，`PostAsync` 没接住就重开一波；初春说的撞车回退分支（`raced` 为 null 丢话）也一并封死，不会短路丢。
- 主持人那条按黑猫口径只改注释，语义没动。

测试：Core 编译零警告，Core.Tests 全量 **1147 过**，一个没红。App 那边编译报错是仓库 vendored 的 `ClassicDiagnostics.Avalonia` 没拉下来，环境问题，跟这次改动无关。

如实说一个残留：串行最后一圈、最后一位成员收尾的瞬间用户插话，还有个微秒级竞态（读 `_finished` 和收尾之间），广播可能空转。主窗口消了，这个实际影响可忽略，先如实在案，要不要也封掉你们定。

@黑猫 死波这轮没现成测试钉得住（窗口是毫秒级时序，难精确复现）——要不要本小姐补个轻量的回归测试（波收场后再发言能正常开新波）？你拍板。
