# Brain 工具：同步、有界、只读的小模型助手

> **状态**：accepted（2026-10-11）。补充 [ADR 0025](0025-子代理默认后台化，报告由唤醒轮交回.md)：「没有同步档」在此处开一个**只读有界**的例外。

## 背景

主代理常遇到两类活：大文件要总结、被截断的工具结果要整理。这类活内容向、有界、只读，不值得开一个后台委派（回执 + 唤醒轮 + 报告的编排心智）——主代理要的是 `AnalyzeImage` 那种「调用 → 等 → 直接拿结果」的同步心智。同时这类活也常需要模型自己再搜一搜（Grep/Read），不是简单把文件丢给模型。

## 决定

新增模型侧工具 **`Brain(task, brainId?)`**：

1. **工具表面**：`task` 必填、直接传提示词；`brainId` 缺省 = 新开一个脑，给了 = 追问那个脑。无 `text`、无 `model` 参数。
2. **同步有界**：主代理那一轮等它跑完，当场返回「整理好的内容 + brain ID」；brain ID 复用 `[sub-session: 短号]` 契约。
   - 墙钟超时 **5 分钟**、内部工具轮 **≤ 30**；到限返回已得部分或失败，主代理可带 brainId 追问续跑。
   - 停止按钮必须能取消脑内部那一轮。
3. **返回预算** ≈ **16KB**：超了脑自截断并写明「更细可追问 brainId」。全文与细节留在脑会话里，主会话只收紧凑总结。
4. **装配只给 Grep + Read**（无 Glob、无 Write）。读工具本就不在审批管里，`AgentPathResolver` 对任意绝对路径放行——脑能直接读产出房间的 `ToolResultSpill` 落盘文件与 `WebFetchCacheSink` 缓存，截断的工具结果因此**不需要主代理传文本**，脑自己按 Notice 里的路径续读。
   - 挂载与委派同源：脑挂在 `EAgentCapability.SubAgent` 能力档下，与 `CreateAgent`/`SendMessage` 一起装配——关委派即关脑；子会话场合（SubAgent/Brain scope）天然不含脑工具，不递归。
5. **模型**：新增设置项 `BrainSubAgentModelName`，对齐 `GeneralSubAgentModel`（设置界面常规 Tab 一行 ComboBox）；空串 = 跟随全局。不给模型清单（ADR 0031 惯例）。
6. **脑 = 真子会话**（`ParentSessionId`）：brainId = 子会话短号；追问 = 带 brainId 续跑那个会话，原始材料与之前的问答都在。`SendMessage` 对脑会话不特判。
7. **提示词现拼**：匿名子代理基座（ADR 0030 段落清单）+ 一句只读纪律（只能用 Grep/Read、任务结束用一段话总结、给结论、被追问时深挖）+ `task` 作为第一条用户消息。不装配角色卡。
8. **生命周期**：认「子会话只增不减」的既有欠账；但脑会话带 **meta 标记**，将来统一清理找得到，也让右栏不列它。
9. **展示**：右栏「子代理」页签**不列脑条目**（没名字、列出来是一串看不懂的东西），只在页签内容顶部显示数量（如「脑 M 个」）。

## 为什么这是 ADR 0025「无同步档」的例外

0025 否掉同步是对**开放委派**否的：中位 185 秒、66% 超一分钟、「已派出」会被模型误读成「已完成」。Brain 的定义恰是它的反面——**有界、只读、内容向**：任务短、不开放、没有反问编排（只能被追问）。同步天然满足「轮次归属」那道承重墙，没有孤儿轮次；主代理那一轮照常自洽封存。

「乐观同步」（N 秒内返回、超时转后台）在 0025 被实测否掉（60 秒窗口只接 34%，撑不起两形态机械）。Brain **不采用**：它是纯同步，不做两种返回形态——脑就是短活，两形态的税不该付。

## 取舍

- **异步**（走 `BackgroundSubAgentDispatcher` 那套）：换来主代理不聋、有进度回执，代价是「已派出 → 唤醒轮」两轮税与回执/报告/唤醒的编排心智。Brain 场景要的是「我现在就要知道」，**否**。
- **text 参数**（把临时内容直接喂给脑）：主代理上下文里已经装得下的小东西，主代理自己就理解了，用不着脑；大文件/截断结果，脑自己 Read 落盘路径。两种都不需要传文本，**否**。
- **Glob**：脑是内容向的，Grep 定位 + Read 读内容即可，目录形状不关心，**否**。
- **model 参数**（调用时指定模型）：ADR 0031 不给清单的惯例之下，模型名由设置项统一，**否**。
- **右栏列脑条目**：脑创建时没有名字，列出来是一串看不懂的条目，且量大会刷屏，改为顶部数量提示，**否**。

## 已知代价

- **聋窗**：同步期间（最长 5 分钟）用户给主代理的插话进队列、不被消费（ADR 0022 已实测）。对策：有界 + 工具卡「查看更多」可直接打开正在跑的脑会话看进度。
- **结果占主会话历史**：返回内容作为工具结果落历史，以后每轮占输入预算。对策：材料留在脑会话，主会话只收紧凑总结（16KB 预算 + 「更细可追问」）。
- **子会话欠账加重**：脑会话量大、短命，「盘上只增不减」增得更快；meta 标记留清理抓手。
- **无异步进度回执**：到限返回部分/失败，主代理要自己决定追不追问。

## 本期不做

- 脑会话自动清理（沿用子会话既有欠账，标记已留）。
- 脑的批量/并发管理（一条回复内多个脑随 `AllowConcurrentInvocation` 自然并行，暂不设上限）。
