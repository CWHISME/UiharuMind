# models.dev 数据改为运行时拉取，静态表降级为离线兜底

> **状态**：accepted（2026-10-31）。取代 [ADR 0097](0097-模型能力表扩项：价格与思考档位进表，视觉改推导加覆盖.md)
> 决定 1 里关于 models.dev 的那半；官网抓取（决定 2）继续留在构建期。
> 界面方案见 [Docs/plan/更多供应商接入设计.md](../plan/更多供应商接入设计.md)。

## 起因

要给「自定义配置」加一个从 models.dev 挑供应商的入口。按原口径（构建期生成表）落地，
就得把能力表从 7 家扩到全部可用供应商——约 7000 行、近 1 MB 生成代码，编译与常驻内存都翻十倍，
而且数据永远滞后到下一次发版。供应商天天变，写死即过期。

## 事实（实测 2026-10-31）

- `https://models.dev/api.json`：5.69 MB / 235 家 / 8938 个模型；支持 brotli（线上约 500 KB），带 `ETag`。
- 只留我们用到的字段后 **1.72 MB**；读 5.7 MB + 解析 + 建索引约 **330 ms**（后台线程）。
- 过滤 + 补默认地址后可用 **216 家 / 7443 个模型**。
- models.dev 只在「地址由各家自己配」时才写 `api`：`@ai-sdk/openai` / `@ai-sdk/groq` / `@ai-sdk/anthropic` /
  `@ai-sdk/google` / `@ai-sdk/xai` 这些**都不写**。按「有 api 才收」一刀切，最常用的几家会全部消失。
- 现有静态表：94 KB 源码 / 893 行 / 7 家。

## 决定

1. **models.dev 数据运行时拉取**，投影后落 `Cache/ModelsDev/snapshot.json`（`Cache` 语义：可再生、用户可随手删）。
   投影字段变就 +1 `schemaVersion`，旧文件直接丢弃重拉。
2. **不设 TTL、不做定时刷新**。联网只发生在两处：打开模型窗口发现本地为空、用户点「刷新」。
   手动刷新走条件请求（`ETag`），304 只更新 `fetchedAt`。两个入口都单飞，失败不自动重试。
3. **读缓存与联网分开**：启动时只读本地文件（一次请求都不发，保住「启动零网络」）。
   不能把读缓存也拖到打开窗口时——`ResolveVision` 在发消息时也要被调用，那时用户可能几个月没开过模型窗口。
4. **静态表保留，降级为离线兜底，且不再扩**。视觉是 `bool`，没有「未知」这一档：
   纯动态化后，首次启动且没网时 `ResolveVision` 会一路判 false，图片被直接丢掉——正是 ADR 0097 那个原案。
   分层顺序：官网价格表（构建期，人工核对） > 运行时快照 > 静态表。
5. **能力查询收成单一入口** `ModelCapabilitySource`，由它做「快照 → 静态表」的分层。
   不去改 `ModelCapabilityTable.g.cs`——生成物，下次重新生成就没了；生成器一行不动。
6. **补一张 11 条的 SDK 默认地址表**（`SdkEndpointFallbacks`），**按 npm 包名**而不是按供应商。
   这是整个方案里唯一手写的端点数据；azure / bedrock / vertex 的地址带账户，一律不猜。
7. **供应商作为数据，不作为类型**：从 models.dev 选的供应商落 `RemoteModelConfig` + 一个持久化的
   `CatalogProviderKey`，不为每家写一个 config 空壳类（现有 7 家已经是 7 个空壳）。
   providerKey 的推导随之从「配置类型」改到「配置实例」（实例上有键就用实例的，否则回落类型映射）。

## 取舍

- **定时刷新 vs 按需刷新**：选了按需。代价是「用户不点刷新就一直是旧数据」；缓解手段是把数据年龄
  摆在弹层底部（超过 30 天变色），让陈旧可见，而不是靠定时器偷偷修。换来的是启动不联网、行为确定。
- **要不要一次性种子（124 KB gzip 内嵌）**：不要。静态表已经兜住 7 家预设的视觉判定，
  再加一份种子等于把「构建期生成」从后门放回来。
- **把能力表扩到 7000 行 vs 运行时快照**：选了快照。代码量不再随供应商增长，数据随时可新。

## 已知代价

- 全新安装 + 无网 + 非预设供应商：视觉会判 false，用户可勾复选框覆盖，联网后自愈。
- 首次打开模型窗口要等一次下载（约 500 KB～5.7 MB，实测 1.2 s）；本地为空时界面显示加载态。
- 快照换代后，已经打开的窗口不会自动重查价格——要订阅 `Changed`。按需刷新的好处是换代只发生在
  用户主动点「刷新」时，触发点少、范围小。
- 少数家的目录不是 `{api}/models`（要 key 才 200，或路径不同）：拉取失败亮提示，地址可手改。
