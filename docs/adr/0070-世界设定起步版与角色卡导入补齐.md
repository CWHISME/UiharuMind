# 世界设定起步版与角色卡导入补齐

> **状态**：accepted（2026-10-07）。

新增「世界设定」内容来源，起步版只做：**关键词命中、常驻（constant）、位置注入（角色人格前/后）、token 预算内截断**。不做递归扫描、多级关键词逻辑（AND/OR/NOT）、深度注入。

理由：token 预算 + 位置控制是「可控注入、防上下文爆炸」的核心价值；递归与多级逻辑工作量大，先跑通再迭代，符合「先最小可用、机制随后补」的口径。

注入形态：`AIContextProvider` 追加一条 User 消息（模板见 `MemoryContextProvider`，`src/UiharuMind.Core/AI/Execution/Tools/Memory/MemoryContextProvider.cs`），**不放进系统提示**——那段随检索结果每轮变化，放进系统提示会把服务端前缀缓存从第 0 个 token 起作废（该处注释已写明理由）。「人格前/后」的位置语义在注入块内分组实现，不拆多个 provider。

实体改为**共享世界书**：命名实体、落 `Data/WorldBooks/*.json`，由 `WorldSettingManager` 按名存取（镜像知识库 MemoryManager）；角色按名挂载（`CharacterData.WorldSettingName`），多个角色可共享同一本。不做旧内嵌格式迁移——共享书形态上线前未产生旧数据，旧 JSON 里残留的 `WorldSetting` 键读入即丢弃。装配点 `AgentAssembler.BuildContextProviders`（`src/UiharuMind.Core/AI/Execution/Assembly/AgentAssembler.cs:110`），prompt-only 与 agent 档两条路都走它、自动都生效；provider 每轮经 `WorldSettingManager` 按挂载名取书。

角色卡导入同步补齐两个字段：`CharacterCardImporter.ImportToCharactorData`（`src/UiharuMind.Core/AI/Character/CharacterCards/CharacterCardImporter.cs:24-44`）当前只映射 name / description+mes_example→Template / first_mes→FirstGreeting / creator+notes→Description / avatar，其余字段解析后丢弃。

- **alternate_greetings**：多份开场白，导入后进「备选开场白」列表（角色编辑页可编辑）；会话仍用默认开场白，不做会话起点选择器。
- **character_book**：导入为世界设定条目（与上文联动）。

`extensions.depth_prompt` 已解析未使用，本轮接入装配——深度注入（`DepthPromptHistoryProvider`，插到供给模型的历史倒数第 Depth 条）。`post_history_instructions` **不设独立字段**：导入时并入 Template 末尾——独立字段让它占系统提示末尾的位置，模型视角与写进提示词无差别，还与人格锚机制重复（都是「末尾指令」），故并入即可，见 `CharacterCardImporter.AppendPostHistory`。personality / scenario 暂不拆独立字段，保持现映射。

合规：只借鉴机制并自行重写实现，不引入 AGPL 等传染性许可证组件（含片段）。

## 改动范围（粗估）

| 项 | 新建 | 改动 | 工作量粗估 |
|---|---|---|---|
| 世界设定 | 实体 + 检索/注入 provider + 单测 | `AgentAssembler.cs`（provider 链）、会话/角色挂载、编辑 UI | Core 1–2 天；UI 另计 |
| 角色卡补齐 | — | `CharacterCardImporter.cs`、角色编辑表单（多开场白选择） | 0.5–1 天 |
| 提示词细节 | — | 卡字段→装配映射 | 0.5–1 天 |

## 不做（后续里程碑）

- 完整提示词可配置化（有序块 + 模板 + 宏）
- 世界设定递归扫描、多级关键词、条目深度注入、向量化激活
- 会话起点「选备用开场白」入口（备选列表保留在编辑页，会话先用默认开场白）
- RAG 增强——知识库被动注入已存在（`MemoryContextProvider`），无工具档照常注入

## 后果

- 术语「世界设定」已入 CONTEXT.md，避免「世界书」「百科」等歧义叫法。
- character_book 导入依赖世界设定实体，两者同批实现。
- 从外部导入的角色卡不再静默丢开场白与世界设定；post_history_instructions 并进提示词，不丢内容。
