# 模型能力表扩项：价格与思考档位进表，视觉改推导加覆盖

> **状态**：accepted（2026-10-29）。补 [ADR 0092](0092-远程模型候选来源改用运行时模型目录，做成通用能力.md)
> 的"目录之外还有一份静态表"口径，不改候选来源。

## 起因

两件事凑到一起：

1. 模型列表想显示单价（输入 / 输出 / 缓存读）。
2. 用户报 CommandCode 下的 MiMo 明明支持视觉，列表显示不支持。

查下来是同一个根因：`ModelCapabilityTable` 从 models.dev 只取了四项（视觉、上下文、输出预算、
是否固定采样参数），而且**查不到就一律当 false**。CommandCode 的目录只有 id（`/v1/models`
标准形状），视觉只能靠静态表；而 models.dev 的 commandcode 快照落后——线上 94 个模型，
表里只有 72 个，缺的 23 个里就有 `xiaomi/mimo-v2.6-*` 全家。缺行 → 全落空 → 非视觉 →
`VisionFallback` 判定要丢图，图片发不出去。**不是显示错了，是功能坏了。**

## 事实（实测 2026-10-29）

- OpenAI 兼容 `/v1/models` 不返回价格；商汤那种富目录也只到 `context_length` / `modalities` /
  `max_output_length`。**没有任何一家有官方价格接口。**
- OpenRouter `GET /api/v1/models` 有 `pricing.{prompt,completion,input_cache_read}`（USD/**token**），
  只覆盖它自己。
- models.dev 的 `cost` 是 USD/**百万 token**，带 `cache_read` / `cache_write` / `tiers`（41 条阶梯）/
  `context_over_200k`（31 条）。同一份数据里还有 `reasoning_options`（86%，每个模型真正支持的
  effort 取值）、`interleaved.field`（37%）、`canonical_model_id`（93%）、`tool_call`（100%）。
- 覆盖率（7 个预设供应商，270 条）：deepseek 4/4 有价、zhipuai 14/17、commandcode 71/72、
  opencode 84/130、opencode-go 31/37、agnes 1/4、sensenova **0/6**。
- CommandCode 是"快照落后"的极端例子：线上 `/v1/models` 94 个，models.dev 收 72 个，
  缺的 23 个全是新模型（MiMo 全家、Qwen3.7/3.8 系、GLM-5、nemotron-3.5-super-vl 等）。
  而官网两张页面对得上：`docs/reference/cli/models` 有 `<code>model/id</code>` 与能力徽标
  （`aria-label="Capabilities: …"`），`docs/resources/pricing-limits` 有每百万 token 的价与
  上下文，**但两页都没有对方的字段**——价格页没有 ID，能力页没有价格，只能按显示名对齐。
- 没有任何一份数据带性能/排行：models.dev 的 19 个字段里只有能力旗标（`reasoning` / `tool_call` /
  `structured_output`）与知识截止，没有跑分。Artificial Analysis 有 API 但要 key
  （无 key 请求返回 `401 {"error":"API key is required"}`），LMArena 之类没有官方接口。

## 决定

1. **两份构建期数据，官网压过第三方快照。**
   - `ModelCapabilityTable`（models.dev，通用）：成本那一栏加 `cost`（四价 + 阶梯）、
     `reasoning_options`（efforts 取值表 / 是否 token 预算形态）、`tool_call`、`canonical_model_id` 索引。
   - `ProviderPricingTable`（供应商官网，权威）：由 `src/scripts/modelInfoGenerator/generate_commandcode_pricing.py`
     抓「模型清单页 + 定价页」，按名称把 `<code>model/id</code>` 与每百万 token 的价对齐。
     先接 CommandCode（94 个模型全覆盖，models.dev 只收了 72 个）。
   - 两者都在构建期定表，运行期零网络、零 key；价格随版本更新，重新跑脚本即可。
   - 生成器统一在 `src/scripts/modelInfoGenerator/`（一家抓取器一个文件），
     出包前跑 `src/Build/updateModelInfo.sh` 一把刷完——刻意不接进 `dotnet build`，
     构建不该因为对端文档站抽风而失败。
2. **不做运行时抓官网。** 应用启动不该依赖某家文档站的 HTML；结构一变就是静默错误。
   抓取器留在构建期，并且**解析不到位就退出码 1**（模型数低于阈值即判定崩了），
   把"页面改版"变成一次显式的重新生成，而不是一张少了一半行的表。
3. **视觉改「推导 + 显式覆盖」。** `BaseRemoteModelConfig.IsVision` 由 `IsVisionOverride ??`
   推导（目录声明 > 预设 > 官网 > models.dev > canonical），写入即视为用户显式指定。
   旧的 `IsVision` 字段 `[JsonIgnore]`，**不迁移**：它分不清"用户关的"与"建模型时预填错的"，
   迁移就等于把 bug 固化。老存档读进来没有 override，下一次读取就按表重新推导——
   这正是 MiMo 自愈的路径。同款三态结构见 `ReplayExistingReasoningOverride`。
4. **canonical 兜底只解「是什么」，不解价格。** canonical 索引收的是 `canonical_model_id`
   （623 条）→ 视觉与两个窗口；价格必须查该供应商自己那一行——价格是每个转售商各挂各的，
   跨家借价等于编。查不到就明说"未公布"，不写 0、不留空（空着会被读成免费）；
   官网明写免费的另有 `IsFree`，那是"能算出 0"，与"没公布"分开。
5. **价格只当参考价，不当账单。** 单位 USD/百万 token，不做汇率换算（DeepSeek 国内站的人民币价
   不是美元价乘汇率）；订阅制/额度制转售商（CommandCode 走账单日历）按额度扣费，挂牌价仅供参考。
   阶梯价（超过某段上下文涨价）只进 tooltip，行上只显示基础价。
6. **排序是候选列表的表头，不在输入框外面。** ComboBox 的弹层里只有 `PART_ItemsPresenter`
   （Semi 的模板里没有任何头部插槽），想把排序放进下拉就只剩"挂在框外"一条路——那会挤掉输入框宽度、
   把这一行排版带歪。所以模型 ID 这一格改自绘：`TextBox` + 右缘箭头 + `Popup`，
   浮层顶部一排「目录 / 输入价 / 输出价 / 缓存读价」（复用 `ListBox.segmented`）压着候选列表。
   代价是不再有 ComboBox 的键盘上下选择；换来的是排序位置正确，以及**能按数据决定'要不要显示排序'**——
   一条价都没公布的供应商（sensenova）不再看到一个点了没反应的开关。

## 后果

- MiMo 那类"供应商目录缺行但别家认得"的模型自愈；`IsVision` 不再被建模型那一刻的判断冻住。
  CommandCode 侧现在是 94/94 有价有视觉（官网覆盖层），models.dev 单独只到 71/72 + 缺 23 行。
- 新增能力露在三处：模型列表行（入/出/缓存读）、模型 ID 候选（三段价；排序头在浮层顶部，
  按输入/输出/缓存读价升序，未公布价格的排最后，无价格的供应商整排不出现）、
  顶栏供应商明细（当前模型单价，峰时按 `PeakPricing` 的倍率放大）。
  `tool_call` 与 `interleaved.field` 在表里待用。
- **官网价格页有两处没建模**：DeepSeek 的峰时/谷时双价（页面显示的是谷时价，峰时翻倍），
  以及 MiniMax M3 这类折扣价（抓的是折后价）。真要算账单得给 `ModelPrice` 加时段与折扣维度，
  现在只能算"按页面主价"的估算。
- 抓取与名称对齐：官网定价页**不含模型 ID**，只能按显示名与清单页对齐。实测 96 个里 94 个对上，
  `typesafe/jev` 两个对不上（页面叫 Jev/TypeSafe，且是决策模型不是对话模型）。同名多行（免费版
  与付费版同名）取有价的那行。脚本每次会打印未命中清单，不静默吞。
- 生成器是"重新生成即改数"：补供应商、刷价格都要重跑并把 `.g.cs` 一起提交。新增一家供应商
  要么等 models.dev，要么照 `generate_commandcode_pricing.py` 再写一个抓取器。
