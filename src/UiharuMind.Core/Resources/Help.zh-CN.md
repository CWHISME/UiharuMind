# UiharuMind 帮助

UiharuMind 是一个跨平台的桌面 AI 助手：本地 GGUF 模型跑在 llama.cpp 上，也能调用任何兼容 OpenAI 接口的在线服务。
除了聊天，它还提供在目录里干活的智能体、多个角色一起说话的群聊，以及截图、OCR、翻译、剪切板历史、自动点击这些
只差一个快捷键的快捷工具。

这份文档就是应用内的使用手册。主界面有四个页面——**对话**、**角色**、**模型**、**日志**——外加一个
**设置**窗口，下面会逐页说明。

## 快速开始

1. 打开**模型**页，先添加至少一个模型。
2. 在线模型：点**添加远程模型**，选一个服务商预设（或自定义），填好接口地址、模型 ID 和 API Key。
3. 本地模型：先到**设置 → 本地模型（文本）**下载或选择一个 llama.cpp 运行时，再把 GGUF 文件放进本地模型目录
   （**模型**页的文件夹按钮），列表会自动重新扫描。
4. 回到**对话**页，在顶部选模型（或用默认的），在右边挑一个角色，就可以开始输入了。

除此之外不需要别的配置。如果列表一直是空的，看文末的**常见问题**。

### 数据放在哪里

所有东西都在 `~/.uiharu` 下（环境变量 `UIHARU_HOME` 可以改这个位置）：配置、会话、角色、知识库、世界书、
技能包、剪切板历史、日志、智能体工作目录都在这里，模型文件和引擎包在 `External/` 下。托盘菜单里有
**打开数据目录**，日志页有**打开日志目录**。

## 模型

**模型**页有四个标签：**对话模型**、**生图模型**、**语音模型**、**获取模型**。

列表里每一项都带状态：本地模型可能正在运行或加载中，远程模型标着 **API**，能看图的标着 **Vision**。右键有
**收藏**、**运行参数…**、**在文件夹中显示**、**模型信息**和删除。文件夹按钮会重新扫描本地模型目录。

### 本地模型（GGUF）

本地模型通过 llama.cpp 的 `llama-server` 运行，运行时是单独下载的：

- **设置 → 本地模型（文本）**里有引擎版本、更新通道（**正式版** / **预览版**）和加载停滞超时；下载列表里每个包
  带着红 / 黄 / 绿启动风险点。
- **模型 → 运行参数…**只改一个模型；你没动过的项跟随全局。里面有上下文长度、GPU 层数、批大小与物理批大小、
  CPU 线程、KV 缓存类型，以及按这些参数估算的显存占用。
- 全局参数也在**设置 → 本地模型（文本）**：适配显存、prompt 线程、并行槽位、连续批处理、Flash Attention、
  KV 缓存类型、MoE 层留在 CPU、KV 缓存放内存、prompt 缓存上限与复用块、上下文移位、完整 SWA 缓存、加载方式、
  环境变量、额外参数。

较重的模型加载前会估算内存占用，启动风险高时会先问你。原生层的显存不足可能让应用失去响应，这个对话框值得
认真看完再点。

### 远程模型

**添加远程模型**要填显示名、完整请求地址（例如 `https://api.example.com/v1/chat/completions`）、请求里用的
模型 ID 和 API Key。高级项：

| 字段 | 用途 |
| --- | --- |
| 视觉支持 | 模型能接收图片；图片问答必需。 |
| 上下文长度 | 以 token 计的上下文窗口，占用读数据此计算。 |
| 思考模式 | 每次请求带的思考强度；**默认**表示跟随模型自身行为。 |
| 最大输出 | 输出预算；留空则用所选思考档的默认预算。 |
| 回传思考内容 | 部分思考模型要求把思考正文随工具调用一起回传，否则请求失败。**跟随预设**按模型自动判断。 |
| 不发送采样参数 | 给拒绝 `temperature`/`top_p`/惩罚项的模型用。 |

API Key 在本机加密保存。**从已有模型复制**可以复用另一个模型的 key 和设置。

### 语音模型

**语音模型**页列出本地朗读（语音合成）与听写（语音识别）模型，在**获取模型 → 语音模型**里下载安装。引擎本身在
**设置 → 本地模型（语音）**（audio.cpp）。可以指定默认朗读模型和默认识别模型；没有它们，朗读和按住说话都不会出声。

### 生图模型

**生图模型**是一份按顺序兜底的列表，供智能体生成与编辑图片使用。条目可以是本地 stable-diffusion.cpp 模型，也可以是
在线服务。从上往下试，只有当前一个不可用（没配置、连不上、被限流或服务端报错）才轮到下一个；被拒绝的 prompt
不会转给下一个模型。**支持编辑**的模型能接收输入图片，不支持的模型在智能体传图时会被跳过。**试一下**可以直接跑一张。

### 嵌入模型

知识库检索需要一个嵌入模型：默认用模型目录里找到的第一个嵌入 GGUF，跑在与对话模型同一套本地 llama.cpp 运行时上。
目录里没有就从**获取模型**下一个，运行时也得装着。高级项（上下文、批大小、物理批大小、GPU 层数）属于嵌入设置，
通常保持默认。

### 获取模型

可以搜名字，也可以直接粘 `owner/repo` 或链接。左栏是仓库，右栏是选中仓库的 GGUF 量化文件：挑一个量化点**下载**，
同一个标签里的队列会显示进度，支持暂停、继续、重试、取消。**推荐**标的是通常该选的那个，旁边会给出内存估算。
仓库带视觉文件时可以顺带下载视觉投影文件。受限仓库需要 HuggingFace token（见**下载源**）。如果还没装 llama.cpp
运行时，会先排入引擎包再下模型。

### 本机占用

**模型**页标题栏里的内存条（对话页模型选择框旁边也有一份）就是加载风险提示所依据的本机快照：可用内存、显存与 CPU。
点开是**本机**明细和**本地模型**列表：每个在跑或正在加载的本地模型进程、各自的内存占用，以及把内存还回去的**停止**
按钮。远程模型不会出现在这里。

## 对话

左侧**新建会话**开一段对话。右栏挑这一段里说话的角色，同时显示上下文占用。标题旁的切换器在**普通对话**与
**智能体**之间切换。

- **模型**：标题栏选的是默认值，单个会话可以覆盖——这时选择框上有 **会话** 标记，选**默认（跟随全局）**即可清掉。
- **输入区**：`Ctrl/⌘+Enter` 发送，`Enter` 换行；文件和图片可以直接拖进窗口。智能体会话里 `Tab` 在**执行**与
  **计划**之间切换。
- **回答过程中**：**停止**会中断当前回复；这时发消息会排成**插话**，在下一个安全点读给模型（读之前可以撤回）。
- **消息操作**：复制、**查看全文**（打开长文本窗）、分支、删除，以及重新生成最后一条回复。
- **搜索**：`Ctrl/⌘+F` 在当前会话里搜，可以连思考内容和工具调用一起搜。会话列表上方的搜索框搜的是会话标题
  和消息正文。
- **思考与渲染**：**自动折叠思考**会在流式输出结束后收起思考段；**原文**选项直接显示 Markdown 源文而不是渲染结果。
- **朗读**：喇叭按钮用角色的声音朗读当前会话的新回复，开关记在角色身上。
- **已放行扩展**：**本会话扩展不再询问**勾上后，原本会先问你的扩展调用在本会话里直接执行；但把浏览器或窗口交回给你、
  打开本地或内网地址，仍然每次都问。
- **上下文面板**：显示本回合与会话累计、缓存输入，以及三个压缩水位——**折叠工具结果**、**记忆压缩**、**截断最旧消息**。
  历史到达记忆压缩水位时应用会压缩这段历史，模型看不到它之前的内容；压缩失败则改为截断最旧的消息。
- **长文本**：太长的消息和工具结果会另开一个文本窗查看，带行号、搜索、自动换行、Markdown 预览和语法高亮。快捷菜单里的
  **文本编辑器**打开的也是它。

### 会话绑定知识库

一个会话可以绑定一个知识库（就是给角色建的那套库，见**知识库**）。输入区旁的面板显示当前绑定的库与索引状态，并可以
打开选择/编辑。检索走索引，所以改完资料要**更新知识库索引**；在那之前对话仍使用旧索引。开了知识库检索工具时模型按需
检索，没开则每回合自动注入相关片段。

### 会话列表

会话按类型分组，可以搜索、改名、删除，也可以进**批量**模式多选删除（正在跑的那几个会跳过）。某个会话正在另一个
UiharuMind 实例里跑时，会给出提示，而不是悄悄分叉。

## 智能体

智能体就是带工具的角色：在角色编辑页打开**启用智能体能力**，它的会话就移到**智能体**一侧，并且不再发开场白。

- **工作目录**：每个智能体会话都在一个目录里干活。**更改…**选目录，最近用过的会列出来。智能体写入或修改的文件在
  **产物**/**会话产物**里，临时草稿放在该目录的草稿目录里，不污染项目。
- **权限档**：**只读**（不执行任何修改类操作）、**自动编辑**（文件修改自动执行，高危命令仍要确认）、**完全自动**
  （都不再询问）。**计划**是另一个开关：智能体先出计划，你切回**执行**它才动手。工具开关、技能、扩展、子代理都在
  角色编辑页里按角色配置。
- **审批**：工具需要授权时会弹卡片，选项是**本次允许**、**本会话总是允许**、**本会话放行同类命令**、**拒绝**。文件写入
  一律会问（写到工作目录之外尤其是），shell 按命令问，可能改动东西或花钱的扩展调用默认也会问。
- **工具**：文件操作（Read、Write、Edit、Glob、Grep）、Shell 执行、网络搜索与读网页、知识库检索、识图、生图、语音、
  任务清单、定时任务、后台任务、委派。
- **扩展**（browser、desktop、image、audio，以及 MCP 服务）不占工具列表，模型需要时才去查——见
  **扩展、MCP 与 Python**。
- **子代理**：可以把一件事交给另一个智能体，只拿回它的报告，原始材料不进主上下文。子会话是真正的会话：从工具卡或
  **子代理**面板点开，可以接着聊，也会随会话一起保存。子代理的能力是它与父代理的交集，永远不会更大。
- **任务清单**：侧栏显示智能体的待办；关掉这个能力，面板一并隐藏。
- **定时任务**：可以建一个到点无人值守跑的任务，那种模式下只允许预授权的 shell 命令。侧栏列出待触发、执行中、已完成、
  失败和已错过的执行，每次执行都能点开成会话。
- **目标模式**：给会话一个目标与唤醒调度（**每轮停下即唤醒**、**循环间隔**、**每天指定时间**、**指定日期**）。模型每轮
  结束后会自己继续推进，可以自判结束，遇到必须你拍板的事会调 `goal.end` 等你。没进展只会放缓唤醒（退避），不会结束
  目标模式。**自动同意审批**能让唤醒轮无人值守地跑，风险很高，开启前需要单独确认。
- **后台任务**：用 **RunBackgroundTask** 起的长命令会在对话里显示状态行，也能在那里停掉。

## 角色与扮演

**角色**页列出所有角色，可以按**类型**（普通/智能体）、**来源**（内置/我建的）、**只看收藏**筛选。导入与复制在列表
右键菜单里；角色上可以直接**开始对话**，有备用开场白时可以选一句。

编辑页有五个标签：

| 标签 | 内容 |
| --- | --- |
| 基础信息 | 名字、出自作品、描述、系统提示词、注入用户卡，以及智能体开关。 |
| 智能体能力 | 工具与能力、技能包、扩展（MCP）、可委派的子代理，各自标出每回合大致的 token 成本。只对智能体显示。 |
| 开场白 | 默认开场白与备用开场白。 |
| 世界设定 | 这个角色挂的世界书。 |
| 高级 | 深度提示词（插在距末尾第 N 条消息处，可指定角色）、采样参数，以及远程模型用的**省略采样参数**。 |

**用户卡**本身就是一种角色：打开**注入用户卡**会把它附加到系统提示里，角色就知道你是谁；改用户卡对所有开启它的角色
立即生效。

### 世界书

世界书是角色之间共享的。条目有关键词、内容、**常驻**、**位置**（角色之前/之后）、**顺序**，还有整本的
**每回合 token 预算**。条目按关键词在预算内激活，角色只为当前相关的设定付钱。

### 知识库

角色可以带一份**角色知识库**：手写的设定笔记加上导入的纯文本文件，切块后建向量索引，对话中作为私密上下文被召回。
库页面显示索引状态（**未建索引**、**需要更新**、**索引健康**、最后索引时间）；更新时先建新索引，旧索引在建成前
一直可用。换了嵌入模型导致维度不一致时，需要重建索引。笔记写得越具体越好：身份、关系、事件、世界规则。

### 语音

角色可以配朗读音色并打开**朗读新回复**，之后当前会话里每条新回复都会念出来。连着的几条按顺序读，停止会跳过剩下的。

## 群聊与离席

群聊是几个角色一起说话的会话。**创建群聊**要定：

- **类型**：**智能体群**（两种角色都能进，成员在一个工作目录里干活）或**普通群**（只有普通角色，没有工作目录）。
- **成员与发言顺序**：按勾选的先后决定发言顺序。
- **调度**：**串行**（成员按顺序一人一轮，一圈即停）或**并行**（被叫醒的成员同时开口，每条发言即时传给还在说的人）。
- **主持人**：并行时用户没 @ 人，只叫醒主持人，由他点名合适的成员。
- **停止策略**：**保守**（被别的成员点名的人说完不再点别人，聊完自动停下）或**激进**（成员可以一直互相点名；静下来后
  没看完全程的人各补一次发言）。
- **群里之前的发言**：给后来加入的成员——**不补**、**摘要**（由主持人或最近发言的成员整理）或**全部**（下一轮一次补发，
  有上限）。
- **工作目录与权限档**（智能体群）：成员默认跟随群聊，也可以按成员改。

跑起来之后：`@名字` 点名；**继续一圈**让串行群继续；审批出现在群输入框上方（十分钟无人应答按拒绝收口）。**群成员**
点开是各成员自己的会话（只读），也可以**私聊**其中一位；每位成员的 token 累计都看得到。**本群产物**收拢草稿目录里的
文件和成员改过的工作区文件。退群的成员会话留在**已退出**里，重新加入会原样拿回，记忆不丢。改名、换主持人、改成员名单
都会改写每个成员的系统提示，下一轮整个上下文按全价重算一遍，之后前缀缓存恢复正常。

### 离席

**离席**把智能体群交给你自己的化身值守。你给它**捎话**（只给化身看）和可选的**重要提醒**，每波结束时它替你把决定拍了，
或者把群停下。**化身设置**里的几道闸会自动收口：化身轮数上限、离席时长上限、连续几波没有新输出就结束、停下之后多久唤醒。

**无限模式（只有手动停止）**会关掉所有闸，只有你能结束——所以目标要写明确。离席中可以**立即唤醒**或**更新**捎话；
**结束离席**会让化身停下，但已经在跑的那一波不受影响。结束后的**离席回执**会说明原因：目标达成、需要你拍板、你手动结束、
到时、化身轮数用尽、连续多波没有新产物。越界写入的审批化身不会替你点，那一条当场拒绝并记进回执。

## 快捷工具

全局快捷键（都可以在**设置 → 快捷键**里改）：

| 功能 | 默认键 |
| --- | --- |
| 截图 | `Alt+Shift+Z` |
| 快捷菜单（快捷询问） | `Alt+Shift+A` |
| 剪切板历史 | `Alt+Shift+S` |
| 快捷翻译 | `Alt+Shift+Q` |
| 自动点击 | `Alt+Shift+G` |
| 按住说话 | macOS 右 Option，其它平台右 Ctrl |

### 截图

截图工具会把屏幕压暗让你拉选区。选区里可以拖动移动、拖边角缩放，`Enter` 截图，`Esc` 取消。放大镜显示像素颜色，
按住 `Shift` 切 RGB/HEX，`Ctrl/⌘+C` 复制色值。截下来的浮动条上有：

- **选中文字**：在图上拖选，把文字框出来。
- **OCR**：提取文字。
- **解释**：让模型看图作答。
- **编辑**：在图上标注，工具栏有保存与取消。
- **复制** / **保存**。

截下来的内容进快捷工具，提取出的文字可以继续交给模型。macOS 上截图与全局快捷键需要屏幕录制与辅助功能权限；重装后
如果权限异常，先在系统设置里删掉旧记录再重新授权。

### 复制弹窗与快捷菜单

复制文字后光标旁会出现一个小按钮，主操作是**解释**；悬停展开**翻译**、**语法分析**、**思考**和**询问**。结果打开在
一个小窗里，可以切原文显示，也可以**转为对话**存成正式会话。

**快捷菜单**快捷键打开轮盘：**文件搜索**（搜文件与目录，粘路径直接跳过去）、**询问**（开一个小窗现问一句，从复制弹窗进来会带上刚复制的文字）、
**文本编辑器**（长文本窗）。

### 剪切板历史

快捷窗口列出最近的复制内容，点一条放回剪切板；右键有**收藏**、**删除**和**清空**。窗口里有搜索框和条目计数。
**设置 → 通用**里的**剪切板历史自动清理（天）**：`0` 表示不清理，收藏项永远保留。

### 快捷翻译

翻译窗口填目标语言、可选的角色（决定风格）、可选的额外要求，以及正文；用当前模型或已配置的远程模型翻译。历史在托盘
菜单的**翻译**里。文本类快捷工具用哪个模型，在**设置 → 快捷工具**里定。

### 自动点击

自动点击窗口录制并回放鼠标、键盘、滚轮动作。会话会保存，可以搜索、改名、复制。时间线里是步骤（左/右键、按键、文字、
延迟、滚轮、循环），可以上下移动、复制、删除，检查器里改选中步骤的参数（位置、延迟、持续、循环次数、文字、按键、
滚轮增量）。回放设置：**重复**（`0` 表示一直播到停）、**间隔**、**速度**。**高级**里可以录鼠标轨迹（帧率、只在按键按下
时录），默认关闭——原始轨迹在不同应用、显示器与输入后端之间回放会不匀。再按一次自动点击快捷键即可停止，窗口里也标着
停止键。

Windows 上要往全屏或管理员权限的游戏里模拟输入，应用需要同等权限：**设置 → 通用 → 全屏游戏输入支持**会在启动时申请
管理员权限，就是为这个。

### 听写

窗口在前台时按住听写键（默认右 Option / 右 Ctrl）说话，松开后识别结果落进输入框。短于 0.3 秒的按键会被忽略。
**在其它应用里使用**打开后，别的应用在前台时也能按住说，识别结果直接粘进那个应用——会短暂借用剪切板再还原，且不进
剪切板历史；macOS 上这条需要辅助功能权限。听写需要本地的语音识别模型（**语音模型**）。

## 扩展、MCP 与 Python

### 扩展

扩展是不占工具列表的能力：模型需要时才去查，默认每一次可能改动东西或花钱的调用都要先问你。内置的四个是：

| 扩展 | 命令 |
| --- | --- |
| `browser` | 页面快照、导航、操作（点击/输入/滚动）、把浏览器交给你 |
| `desktop` | 列窗口、窗口快照、操作窗口、启动应用、把窗口交给你 |
| `image` | 生成或编辑图片 |
| `audio` | 语音合成、音频转写 |

把浏览器或窗口交给你、打开本地或内网地址，即使勾了「不再询问扩展」也每次都会问。每个扩展都可以按角色关掉。

### MCP 服务

**设置 → 智能体 → MCP 服务**管理 MCP server。一个 server 有名称、传输方式（**stdio**：启动命令、参数、环境变量；
**HTTP**：地址与请求头）、一行给模型看的描述，以及**托管此 server**——托管是全局的，哪些智能体能用它下面的工具则在
角色编辑页里按角色定。**测试连接**会先保存，再连上去列出工具。配置文件就是标准的 `mcpServers` 格式，可以直接从别的
MCP 客户端粘过来；**从文件重载**会读外部改动。

项目也可以在工作目录里放 `.mcp.json` 自己声明 server。因为那个文件是随仓库提交的，第一次有项目要启动自己的 server 时
会先让你确认，并列出要执行的命令；运行与窗口交接类调用照旧要问。批准过的项目列在**允许自行启动 MCP 服务的项目**下，
可以随时撤销。

### 技能包

技能是一个带 `SKILL.md` 的目录（名称、描述，加上按需加载的正文）。技能包放在技能目录里（**打开技能目录**），任意深度
都会扫描；名字与目录名不一致的会被拒绝。**设置 → 智能体 → 技能包**管理这些包，也能新建；某个智能体能使用哪些技能在它的
编辑页里挑。智能体对话里输入 `/名字` 可以显式调用，标为 **user-invoked** 的技能只走这条路。**把技能清单发给模型**可以在
上下文紧张时把清单从提示里拿掉——代价是模型不再自己想到技能。

### 受管 Python 环境

**设置 → 智能体 → 受管 Python 环境**把解释器与环境分开：你指定宿主解释器（或从 `PATH` 自动探测），应用建一个虚拟环境，
智能体通过 shell 工具跑 Python、装包也只装进这个环境，系统里的 Python 不会被碰。

## 设置

设置是一个窗口，左侧三组，顶部有**搜索设置**，可以直接跳到某一行。

### 通用

**应用更新**显示已装版本，并到 GitHub releases 检查更新；匹配的包会下载到数据目录，点**安装**解包。**界面**里有
**语言**（English、简体中文，切换后主界面立即生效）和**主题**（跟随系统 / 浅色 / 深色）。**通用设置**里有
**剪切板历史自动清理（天）**、**全屏游戏输入支持**（仅 Windows）和**开机自启动**。

### 快捷键

改截图、快捷菜单、剪切板历史、快捷翻译、自动点击，冲突会被拒绝；另有**语音输入**：**按住说话**与**在其它应用里使用**。

### 快捷工具

文本类快捷工具（解释、翻译、思考、询问）的**默认模型**，留空跟随标题栏模型。OCR 与看图提问的**默认视觉模型**，留空跟随
自动选择。

### 智能体

- **常规**：默认权限档、子代理（通用 / 脑 / 探索档）用的模型（留空回退主代理模型）、**记忆清单字数上限**——
  交给智能体的记忆索引（每份笔记的文件名与首行）能有多长。全局能力设置也都收在这里：
  - **模型 Shell**：模型用命令行工具执行命令时实际调用的解释器（选「自动」跟随系统默认，或指定
    Git Bash / PowerShell 等）。
  - **受管 Python 环境**：解释器归你、虚拟环境归我们的那套（见上文）。
  - **网络搜索 API key** 与**搜索引擎状态**：兜底顺序，每个都能**测试**。
- **MCP 服务**、**技能包**：见上文对应小节。
- **化身设置**：离席那几道闸。
- **生图模型列表**在模型页（**生图模型**），设置页不再单独列。

### 本地模型（文本）/（语音）/（生图）

三个本地引擎页：引擎版本与更新通道、各引擎参数（见**本地模型**），语音与生图页还有已安装/可下载的模型列表。
**恢复默认**只重置本页参数，不动引擎版本和下载源。

### 下载源

**模型源**对**获取模型**里的搜索和下载都生效：HuggingFace、hf-mirror（HuggingFace 镜像）、ModelScope，或自定义的
HuggingFace 兼容地址。可选的 **HuggingFace token**（受限仓库需要，也会发给镜像与自定义地址）、**ModelScope token**
（私有仓库才需要）和**GitHub 代理前缀**（给引擎包下载用）。

### 帮助与关于

**帮助**就是这份文档，有对应语言的译文时按界面语言显示。**关于**显示版本、许可证、一段简介、字体说明，以及应用用到的
开源项目链接。

## 权限、日志与常见问题

### 权限档

| 档位 | 行为 |
| --- | --- |
| **只读** | 完全不执行修改类操作：能读能搜，不写，也不跑 shell。 |
| **自动编辑** | 文件修改自动执行；shell 命令与高风险调用仍要确认。 |
| **完全自动** | 所有操作自动执行，不再询问。 |

**计划**模式与这三档正交：智能体先出计划，你切到**执行**它才动手。群里默认跟随群聊的权限档，也可以按成员改；定时任务
与目标模式的唤醒轮走受限的预授权集合——目标模式可以自动同意一切，但会先警告你。每一次审批、每一条命令都记在会话里。

### 日志

**日志**页实时显示应用日志。**级别**设的是记录的最低级别（**全部**、**警告及以上**、**仅错误**）——它决定什么被写下来，
不只是显示出来的部分；**类别**区分普通日志、模型请求与模型响应。可以导出当前筛选结果、清空视图，或打开日志目录。
日志轮转后旧条目的正文可能已被清掉，页面上会标出来。

### 常见问题

**模型目录里有文件，列表里没有。** 确认是支持的 GGUF，模型目录就是应用扫描的那个（**模型**页的文件夹按钮会显示路径），
然后重新扫描。本地模型还得先装运行时。

**本地引擎起不来。** 到**设置 → 本地模型（文本）**装或更新引擎，检查加载停滞超时。**日志**页会显示最近一次错误；风险高的
加载也可能只是内存不够。

**远程模型调用失败。** 检查接口地址是否是完整请求地址、模型 ID 是否存在、key 是否有效、账号有没有该模型权限。采样参数
固定的模型需要打开**省略采样参数**。

**图片被拒或被忽略。** 模型要开**视觉支持**，否则图片问答会去找可用的视觉模型，智能体的识图工具也能绕过去。

**macOS 上截图或快捷键没反应。** 到系统设置 → 隐私与安全性里给屏幕录制与辅助功能授权。旧记录还在但无效时，删掉旧记录、
重启应用再授权一次。直接跑裸可执行文件是拿不到这些授权的，要用签名过的 `.app`。

**知识库检索不到东西。** 加完资料要**更新知识库索引**，嵌入模型也要可用——本地运行时加模型目录里的嵌入 GGUF。维度不一致需要
重建。

**按住说话没反应。** 需要本地语音识别模型，检查**语音模型**和默认识别模型。

**群成员卡住了。** 在等审批就到群输入框上方处理；否则从**群成员**点开他自己的会话，看他在干什么。

**输入模拟进不了游戏。** Windows 上让 UiharuMind 和游戏跑在同等权限，或打开**全屏游戏输入支持**。

**开两个实例。** 多个实例可以共享同一份档案；某个会话正在别处跑时，这边只读，等它跑完。跑脚本、拍截图时把
`UIHARU_HOME` 指到一个临时目录，就不会动到真实数据。
